# Pasumai AI Frontend

React-based web interface for the Pasumai AI agricultural disease detection system.

## Setup

```bash
npm install
npm start
```

The app runs on http://localhost:3000

## Features

- Dashboard with scan history
- Image scanner for leaf, soil, and land analysis
- Results viewer with confidence scores
- Responsive design

## Environment Variables

Create `.env` file:

```
REACT_APP_API_URL=http://localhost:5000
```
